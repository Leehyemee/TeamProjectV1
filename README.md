# 온라인 동물보호센터(발바닥)

### 프로젝트 개요
* 프로젝트명: 발바닥
* 개요: 유기동물 입양 및 보호를 위한 웹사이트를 개발하는 프로젝트입니다. <br>
       사용자가 유기동물을 입양하거나, 후원을 진행할 수 있도록 다양한 기능을 제공합니다.

### 프로젝트 목적
* 프로젝트의 주제 선정이유: 유기동물 보호소의 입양률을 증가시키고, <br>
                      후원 참여를 독려하기 위해 프로젝트를 진행합니다. 
                      유기동물 입양에 대한 정보를 보다 쉽게 제공하고, <br>
                      사용자들이 직접 입양 신청을 할 수 있도록 하여 <br>
                      유기동물 보호 활동을 활성화하는 것이 목표입니다.<br><br>
* 참고 사이트 : 
    1. 카라 : https://www.ekara.org/<br>
    2. 동물 자유연대 : https://www.animals.or.kr/<br>
    3. 한국동물보호소협회 : https://www.petkas.co.kr/html/

### 프로젝트 요구사항 정의
* 프로젝트 결과물에서 제공하는 기능 <br>
  이 프로젝트를 통해 제공되는 주요 기능은 다음과 같습니다:
  - 유기동물 정보 제공 및 입양 신청 시스템
  - 후원 결제 시스템 및 내역 조회
  - 커뮤니티 기능 (입양 후기, 봉사활동 후기 공유)
  - 관리자 기능 (유기동물 등록, 게시물 및 신고 관리)

### 프로젝트 기술스택
* 프로젝트에 사용한 기술 및 버젼<br>
    프론트엔드: HTML, CSS, JavaScript, Bootstrap<br>
    백엔드: Spring Boot, Java<br>
    데이터베이스: MariaDB
    인프라: AWS (EC2, S3?)
* API: 카카오 지도 API (위치 안내), 결제 API (후원 기능), ++
